# 工作区（workspace）

把你的 Excel / Word / PDF 直接放进这个目录，然后在对话里**直接说文件名**就行：

```
You: 读 成绩表.xlsx，统计各班人数
You: 在 考试安排通知.docx 里找张三在哪个考场
```

agent 会自动用相对路径调用 `read_excel` / `read_word`，不需要你写完整路径。

## 路径解析规则

| 你给的路径 | 解析到 |
| --- | --- |
| `成绩表.xlsx` | **本目录（工作区）** |
| `2024级/成绩表.xlsx` | 本目录下的子目录（可以建子文件夹分类） |
| `./src/index.ts` | 项目代码目录（`./` 开头表示"相对项目"） |
| `D:\旅梦资料\成绩表.xlsx` | 绝对路径，工作区外的文件也能读 |

工作区里没有、但项目目录里有时，会自动退回项目目录解析，并在结果里给出一条提示（向后兼容）。

## 换一个工作区位置

默认就是本目录（`<项目>/workspace`）。想换成别的文件夹，在项目根目录的 `.env` 里加一行：

```
WORKSPACE_DIR=D:\旅梦资料
```

## 注意事项

- 本目录被 `.gitignore` 忽略，**不会提交到 git**（学生名单、成绩等敏感文件不会被推上去）
- 单表默认最多解析 5000 行 / 30 列，超大文件用 `maxRows` / `maxColumns` 放宽
- 旧版 `.doc`（二进制）不支持，请先另存为 `.docx`；纯扫描件 PDF 没有文字层，读不出内容
- 会话存档在项目根目录的 `.sessions/`（也已加入 `.gitignore`）
